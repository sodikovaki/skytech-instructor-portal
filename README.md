# SkyTech Academy portal

The private portal for SkyTech Academy instructors and office staff.

Everything in this repository except the page code is encrypted (AES-256-GCM). The files in
`vault/` and `data/` can only be read in the portal after entering a SkyTech passcode.

To view the portal, open https://sodikovaki.github.io/skytech-instructor-portal/ and enter your passcode.
For access, contact info@skytechacademy.org.
